# Kalutskiy — веб‑платформа на Node.js + MySQL

Данный репозиторий содержит полноценный серверный веб‑проект на **Node.js** с использованием **Express**, **MySQL** и серверного рендеринга через **EJS**.  
Проект реализован по архитектуре MVC и подходит для курсовой / учебной работы, а также для демонстрации production‑подхода к backend‑разработке.

---

## 🚀 Используемые технологии

### Backend
- **Node.js** — серверная JavaScript‑платформа  
- **Express.js** — маршрутизация и middleware  
- **MySQL** — реляционная база данных  
- **mysql2** — драйвер MySQL с Promise API  
- **dotenv** — переменные окружения  
- **bcryptjs** — безопасное хэширование паролей  
- **express-session** — сессии пользователей  
- **connect-flash** — flash‑уведомления  
- **multer** — загрузка файлов  
- **method-override** — поддержка PUT/DELETE из HTML‑форм  
- **helmet** — базовая HTTP‑защита  
- **morgan** — логирование запросов  

### Frontend
- **EJS** — серверные HTML‑шаблоны  
- **CSS (production)** — готовые стили  
- **Vanilla JavaScript** — клиентская логика  

---

## 🧱 Архитектура

Проект построен по принципу **MVC**:

- **Model** — MySQL + SQL‑схемы
- **View** — EJS‑шаблоны
- **Controller** — Express‑роуты и middleware

## 🗄️ База данных

### Создание схемы
```bash
mysql -u root -p < DB_schema.sql
```

### Заполнение тестовыми данными
```bash
mysql -u root -p < DB_seed.sql
```

### Через Node.js сидер
```bash
npm run seed
```

---

## ▶️ Запуск проекта

### Установка зависимостей
```bash
npm install
```

### Режим разработки
```bash
npm run dev
```

Сайт будет доступен по адресу:  
`http://localhost:3002`
